## 使用流程

投稿者在視覺／音樂／表演藝術區按「填寫投稿表單」，另開完整頁填寫，或在互動工具成果區提交已部署的工具網址。投稿者不需建立會員；送出成功後顯示投稿編號，作品先待審，不立即公開。

管理者由頁尾「管理者登入」進入 Google 帳號限定後台，檢查連結與附件後核准、不公開或下架。網頁不自動寄信；修改與退回需求由管理者依聯絡信箱處理。

## 開發與驗證

```
npm ci
npm test
node tests/browser.spec.cjs
```

瀏覽器測試使用本機 Chrome 與模擬 GAS 回應，不能取代真正的雲端收件驗收。截圖與結果在忽略的 `.local/`。

公開網站僅包含 `index.html`、`site.js`、`site-content.js`、`site-config.js`。GAS 原始碼在 `gas/`，`.clasp.json` 與本機管理員設定不進版控。Actions 依白名單打包，避免把開發與後端檔案放上 Pages。

## 測試邊界

- 附件最多 5MB，每日最多 30 件投稿、最多 3000 件測試紀錄；不收 HTML 程式。
- 新建試算表與 Drive 資料夾保持私有；核准附件後才切換為知道連結可檢視，下架回收該分享權限。
- 公開 API 不含聯絡信箱、審核註記、待審作品；GAS 的管理方法各自驗證管理者身分。
- 尚無 CAPTCHA、通知信或惡意附件掃描，僅供虛構資料隔離測試。
- Google 首次授權與測試站推送已由使用者確認；實際驗證範圍以 handoff.md 為準。
